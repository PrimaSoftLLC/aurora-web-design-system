Правила применения

  • Одна оболочка содержит один input или textarea с dsInput. Для checkbox и select эта директива не предназначена.
  • Значение, disabled, readonly, required и нативные параметры задавайте на контроле, не на оболочке.
  • Form field не выполняет валидацию и не выбирает момент ошибки: вставляйте dsError по правилу приложения.
  • Нижняя область связана с контролом через aria-describedby. Собственные ID сохраняются; единицы в suffix можно связать дополнительным ID, как в примере скорости.
  • Интерактивный prefix/suffix принадлежит приложению: его disabled задаётся отдельно. Не скрывайте фокусируемую кнопку через aria-hidden.
  • Без видимого label задайте aria-label или aria-labelledby. Пустые строки резервируются, но не создают доступного имени.
  • Многострочные подписи и сообщения увеличивают высоту. Textarea допускает нативное изменение высоты; автоматический resize и плавающий label сюда не добавлены.

Параметры и области

Параметр Тип По умолчанию Назначение
label string Нет Видимая подпись оболочки; обязательность читается с контрола.
collapseEmptyLabel boolean false Убирает только пустую верхнюю область.
collapseEmptyMessages boolean false Убирает нижнюю область, только когда нет hint и error.
dsInput: mono boolean false Моноширинное оформление значения.
dsInput: maxRows number 0 (без ограничения) Максимальная высота textarea в строках при ручном растягивании; далее — прокрутка.
dsInput: id string Генерируется Нативный ID, связанный с подписью.
dsPrefix / dsSuffix Проекция Нет Содержимое до/после контрола в одной строке.
dsHint / dsError Проекция Нет Нижняя область; переданная ошибка заменяет весь hint.

Оболочка и dsInput не добавляют CVA или valueChange: работают нативные события и стандартные value accessors Angular Forms.
