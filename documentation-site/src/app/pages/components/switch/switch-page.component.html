Правила применения

Для настройки, которая применяется сразу, используйте Switch. Для выбора с общим подтверждением используйте Checkbox.

Клик по дорожке или тексту и клавиша Space меняют значение. Подпись называет настройку в обоих положениях.

Параметры

Параметр Тип По умолчанию Назначение
checked boolean false Значение вне Angular Forms.
checkedChange boolean — Событие пользовательского переключения.
disabled boolean false Недоступность контрола.
label, description string — Подпись и необязательное пояснение.
labelPosition 'left' | 'right' right Сторона текстового блока.
aria-label, aria-labelledby, aria-describedby string — Доступное имя и внешнее описание нативного контрола.

Токены

Токены Назначение
--ds-brand, --ds-border-control, --ds-on-brand Цвета дорожки и бегунка доступного контрола.
--ds-surface-disabled, --ds-border-control-disabled Заливка и граница дорожки в обоих недоступных состояниях.
--ds-fg-control-disabled Цвет недоступного бегунка. Положение бегунка показывает значение.
--ds-control-h, --ds-gap-sm Размер области нажатия и расстояние до подписи.
--ds-focus-width, --ds-focus-color, --ds-focus-offset Кольцо клавиатурного фокуса.
