Angular UI-kit Aurora. Выберите компонент в меню слева.

  • Form field — оболочка поля и директива нативного ввода.
  • Icon — иконка.
  • Button — кнопка с подписью и иконками.
  • FAB — главное действие области.
  • Checkbox — независимый и частичный выбор.
  • Switch — переключатель настройки.
  • Spinner — ожидание операции с неизвестным прогрессом.
