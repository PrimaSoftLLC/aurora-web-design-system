# DsSwitchComponent

Импортируйте `DsSwitchComponent` из `@primasoftllc/design-system/angular` и добавьте
в `imports` компонента приложения. Подключите общие стили Aurora.

Switch меняет настройку сразу. Для выбора, который применяется общей кнопкой
«Сохранить», используйте Checkbox. Подпись называет настройку в обоих положениях.

```html
<ds-switch label="Показывать треки" [(checked)]="showTracks"></ds-switch>
```

- `checked` и `disabled` по умолчанию равны `false`.
- `checkedChange` сообщает булево значение при пользовательском переключении.
- `label` и `description` задают текст. `labelPosition` размещает его справа
  (`right`, по умолчанию) или слева (`left`).
- `aria-label` и `aria-labelledby` задают доступное имя без видимой подписи.
  `aria-describedby` дополняет описание, связанное с нативным контролом.

Для Angular Forms используйте `formControl`, `formControlName` или `ngModel`.
В этом режиме значение задаёт форма. Недоступность можно задать через форму
или вход `disabled`. Программные изменения не вызывают `checkedChange`.

Tab переводит фокус на переключатель, Space меняет состояние. Клик по подписи
или пояснению активирует тот же контрол. У недоступных вариантов общие цвета,
а положение бегунка сохраняет видимое различие между «вкл.» и «выкл.».
