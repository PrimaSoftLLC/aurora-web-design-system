Тост — результат действия на инверсном грунте, чтобы его нельзя было спутать с баннером.

**Потребитель задаёт** `tone` и текст в `children`, при необходимости одно действие (`action` + `actionLabel`, обычно «Отменить»), `onClose`, `icon`.

- Тосты стоят в `DsToastStack` на уровне страницы.
- Одно действие, не больше.
