Поверхность региона: 1px граница на скруглённой поверхности, шапка, тело, подвал.

**Потребитель задаёт** содержимое в `children`, при необходимости `eyebrow`, `title`, `actions`, `footer`, `padding`, `scroll`, `height`, `flush`, `bodyStyle`, `style`.

- `padding={false}` — когда тело таблица или карта и должно доходить до краёв.
- `scroll` делает тело контейнером прокрутки вместо страницы.
- `flush` — без рамки и скругления, для панели, заполняющей регион каркаса.
- Тело — flex-колонка: ребёнок с `flex:1` (карта, таблица) заполняет её. Для обычного потока — `bodyStyle={{display:'block'}}`.
- `actions` и `footer` принимают и детей со `slot="…"`.
- Замена `Card`: вместо радиуса 0 и брендовой линии 2px — радиус 12px и граница 1px. Соседние панели разделяет просвет фона.
