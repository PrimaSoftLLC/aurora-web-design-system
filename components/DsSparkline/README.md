Микротренд в ячейке таблицы или строке объекта: только форма, без осей и подписей.

**Потребитель задаёт** `data`, при необходимости `width`, `height`, `tone` или `color`, `area`, `dot`, `label`.

- `null` — пропуск данных, линия разрывается.
- `series` (по умолчанию) — `--ds-series-1`; статусные тоны — только когда само направление хорошее или плохое (слив топлива, превышения).
- Без `label` спарклайн скрыт от вспомогательных технологий — правильно только если то же число уже есть в строке текстом.
- В плотной таблице выключите `area`.
