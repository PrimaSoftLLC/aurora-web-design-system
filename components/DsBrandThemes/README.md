# Цветовые темы

## Подключение темы

`DEFAULT` и `RED2` используют одинаковые компоненты и семантические роли.
Атрибут `data-ds-theme` выбирает бренд, `data-ds-appearance` — светлый или
тёмный режим. Переключатели каталога обновляют значения в таблице выше.

```html
<section data-ds-theme="RED2" data-ds-appearance="dark">
  <!-- Компоненты наследуют токены этого контейнера. -->
</section>
```

## Изменение палитры

Исходные значения хранятся в `tokens/source.json`. Сборка генерирует CSS;
правки в сгенерированных файлах будут перезаписаны. Цвета нового бренда
проверяйте в светлом и тёмном режимах, включая состояния контролов.

Для подготовки значений используйте [подбор цветов темы](../DsBrandPick/README.md).
Для состояний объектов используйте [цвета статусов](../DsStatus/README.md).
