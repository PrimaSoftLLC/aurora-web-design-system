Поле длительности «дни · часы · минуты» — «стоянка дольше», «поездка короче», интервалы отчётов.

**Потребитель задаёт** `label`, `value` (`{d, h, m}`) и `onChange`, при необходимости `hint`, `error`, `warning`, `showDays`, `disabled`, `width`.

- Построено на общих токенах поля: та же высота, рамка и кольцо фокуса, что у `DsField`. Единицы вынесены из маски, чтобы их можно было перевести.
- `warning` — янтарная рамка и пояснение («дольше интервала отчёта»).
- `showDays={false}` убирает сегмент дней.

**Не делайте:** использовать его для времени суток — для этого `DsField type="time"`.
