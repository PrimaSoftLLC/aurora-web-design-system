Состояние объекта глифом в тонированном диске; в движении глиф повёрнут по курсу.

**Потребитель задаёт** `state`, при необходимости `course` (градусы, 0 — север), `size`, `bare`, `label`.

- Состояния: `moving`, `parked`, `offline`, `invalid`, `alarm`, `nodata`. Цвет глифа — `--ds-state-*`, диск — тон статуса.
- `size` 28 по умолчанию, 20 — в плотной ячейке таблицы; `bare` — без диска, для наложения на карту.
- У глифа всегда `role="img"` и подпись; передайте локализованную строку в `label`.
- Стоянку и «нет данных» различает глиф, а не оттенок серого.
