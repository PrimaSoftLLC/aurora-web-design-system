Пустая область: глиф, заголовок о том, чего нет, одна строка почему и действие, которое это исправит.

**Потребитель задаёт** `title`, при необходимости `icon`, `description`, `action`, `secondary`, `tone`, `size`.

- Три случая одним компонентом: ничего не подошло под фильтр, ничего ещё нет, запрос не удался.
- Всегда называйте действие: «Изменить период», «Повторить».
- Ошибка — `tone="danger"` с повтором; это не баннер. Баннер поясняет существующее содержимое, пустое состояние заменяет отсутствующее.
- Стоит внутри контейнера, который держал бы данные, никогда не на весь экран. `size="sm"` — для узких контейнеров.
- Загрузка — не пустое состояние: пока данные идут, показывайте `DsSkeleton`.
