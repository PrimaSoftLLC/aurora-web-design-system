# Светлый и тёмный режим

## Как подключить

Задайте `data-ds-appearance="light"` или `"dark"` на корне страницы.
Компоненты получат цвета через CSS-токены. Атрибут на вложенном контейнере
позволяет, например, оставить светлую панель внутри тёмной страницы.

```html
<html data-ds-theme="DEFAULT" data-ds-appearance="dark">
```

## Что проверять

Проверяйте основной и второстепенный текст, поля, наведение и выбранные
состояния в обоих режимах. Для инверсной поверхности используйте
`--ds-fg-on-inverse` и статусные `--ds-*-fg-on-inverse`.

Пример выше закрепляет light и dark локально для сравнения.
[Цветовая тема](../DsBrandThemes/README.md) и
[плотность интерфейса](../DsDensity/README.md) задаются независимо.
