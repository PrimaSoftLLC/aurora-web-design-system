Декартов график системы: линия, область или столбцы — дизайн того графика, который продукт рисует ECharts.

**Потребитель задаёт** `series` и `categories`, при необходимости `type`, `title`, `subtitle` (период и число точек), `height`, `yUnit`, `yMin` / `yMax`, `legend`, `toolbox`, `zoom`, `showMinMax`, `thresholds`, `markAreas`, `stepped`, состояния `loading` / `empty`, `actions`. Ширину график меряет у родителя.

- Цвета серий — `--ds-series-1…8`, темонезависимы: у датчика свой цвет в любом бренде.
- Разрыв телеметрии остаётся разрывом: `null` рисуется пропуском, линия через молчание не проводится.
- Заливаемая серия доходит до своего нуля: `area` и `bar` сами расширяют ось до 0. Обрезать можно только линию — закрепите `yMin` / `yMax`, когда шкала задана датчиком.
- `stepped` — для дискретного состояния (зажигание, цифровой датчик).
- Загрузка — скелетон, не спиннер.
- Заголовок слева; без градиентов, теней серий, 3D и круговых диаграмм.
- Для продукта токены переводятся в `EChartsOption` через `echartsTheme.js`.

**Не делайте:** внешние отступы у графика — их задаёт `DsPanel`.
