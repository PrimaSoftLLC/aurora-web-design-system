Панель действий над N выбранными строками таблицы — режим, а не хром: при `count` 0 её нет.

**Потребитель задаёт** `count`, при необходимости `total` (включает «Выбрать все»), `noun` во множественном числе, `onSelectAll`, `onClear`, глаголы в `actions` или детьми со `slot="actions"`, `floating`.

- Два–четыре глагола, которые имеют смысл для многих строк сразу: назначить группу, отправить команду, экспорт, архив. Остальное — за одной кнопкой `more_vert`.
- Разрушающее действие — `tone="danger"` и подтверждение в `DsDialog`. Никогда не удаляйте прямо из панели.
- `floating={false}` — плоская полоса, когда она стоит внутри рамки, уже отделяющей её от строк.
