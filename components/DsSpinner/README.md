Индикатор загрузки.

**Потребитель задаёт** при необходимости `size` (16 в строке, 20 по умолчанию, 32 в панели, 48 на странице), `thickness`, `tone`, `label`.

- `tone="inverse"` берёт `currentColor` — для брендового или статусного грунта.
- Внутри таблицы и графика предпочитайте `DsSkeleton`: спиннер ничего не говорит о форме данных.
