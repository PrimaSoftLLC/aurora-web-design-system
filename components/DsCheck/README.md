Общий вид и модель состояний любого бокса выбора в системе: `'off' | 'on' | 'some'`, квадрат с галочкой или круг с точкой.

**Потребитель задаёт** `state`, при необходимости `radio`, `disabled`, `hover` (ховер рисует родитель, который владеет событиями указателя) и `size` (везде в продукте 18).

- Компонент только рисует и ничего не объявляет. Для формы оберните его в `<label>` с настоящим input — это `DsCheckbox`; для отдельного контрола — `DsCheckButton`.
- `some` — смешанное состояние агрегата: пользователь, группа, «выбрать всё».

**Не делайте:** собственный третий вариант чекбокса — раньше один и тот же бокс существовал в трёх копиях и разъехался.
