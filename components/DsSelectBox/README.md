Трёхпозиционный бокс выбора со своей зоной нажатия — для дерева объектов, где у строки нет подписи рядом с боксом.

**Потребитель задаёт** `state` (`on` · `some` · `off`), `onChange(next)` и `label` — что именно выбирается («Выбрать все объекты Петрова С.»).

- `some` — частично выбранный пользователь или группа.
- Следующее состояние: `off` → `on`, `on` / `some` → `off`.

**Не делайте:** использовать его в форме — там `DsCheckbox` с подписью.
