Шапка экрана: хлебные крошки, кнопка «назад», заголовок, мета, действия и полоса табов, которые каждый экран раньше собирал руками.

**Потребитель задаёт** `title`, при необходимости `eyebrow`, `breadcrumbs`, `onBack`, `meta`, `actions`, `tabs`, `border`.

- Последняя крошка — текущая страница, без `onClick`.
- `tabs` — `DsTabs tone="underline"`, прижаты к нижней границе.
- Форма длиннее восьми полей или со своими табами — это экран с `DsPageHeader`, а не модальное окно.
