Плавающая кнопка действия — единственная кнопка системы с настоящей тенью (`--ds-shadow-md`, на ховере `--ds-shadow-lg`), потому что она парит над картой или длинной таблицей.

**Потребитель задаёт** `icon` (по умолчанию `add`), `label` — обязателен для доступности и становится текстом при `extended`; при необходимости `tone`, `size`, `disabled`, `onClick`.

- `extended` — пилюля с иконкой и подписью вместо круга.
- `tone="surface"` — белая кнопка для рейки карты; `accent` — второе действие на карте.
- На карте мониторинга это «Добавить объект» / «Добавить геозону».

**Не делайте:** FAB там, где есть обычная панель инструментов — там `DsButton`.
