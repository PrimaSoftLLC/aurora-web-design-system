Единственный примитив иконки: глиф Material Symbols Outlined, самохостящийся шрифт, глиф — текст элемента, а не SVG.

**Потребитель задаёт** `name` — лигатуру из словаря продукта (README, «Иконографика»), при необходимости `size` и `rotate`.

- Размер — всегда токен: `var(--ds-icon)` внутри контрола, `--ds-icon-lg` отдельно стоящий, `--ds-icon-sm` в плотных строках, `--ds-icon-xs` при тексте 11–12px. Все четыре уменьшаются в compact.
- Поворот несёт смысл: `navigation` — курс объекта, `straighten` на −45° — линейка, `priority_high` на 180°. Для украшения не поворачивайте.
- По умолчанию декоративна (`aria-hidden`). `label` — только когда глиф один несёт факт: тогда `role="img"` и доступное имя.

**Не делайте:** свой `<span class="material-symbols-outlined">` в обход компонента; литеральный размер; новый глиф, когда в словаре есть подходящий.
