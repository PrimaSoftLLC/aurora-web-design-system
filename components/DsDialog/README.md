Модальное окно — тратится только на подтверждение необратимого, создание или правку одного объекта и короткую задачу из не более чем трёх шагов.

**Потребитель задаёт** `open`, `title`, при необходимости `description`, тело в `children`, `actions`, `onClose`, `size`, `tone`, `scroll`, `dismissable`.

- Высота по содержимому, до `min(90vh,760px)`. Размер — решение: `sm` 420 для подтверждения, `md` 560 для формы объекта, `lg` 760 для двух колонок или степпера, `xl` 960 для таблицы или карты.
- Действия справа в порядке чтения: отмена, затем подтверждение; ровно одно главное (`danger`, когда подтверждение разрушает). Кнопка повторяет глагол из заголовка.
- `tone="danger"` рисует глиф в шапке, чтобы разрушающее подтверждение узнавалось до чтения.
- `onClose` даёт Escape, клик по скриму и крестик. `dismissable={false}` оставляет крестик, но игнорирует Escape и скрим. Без `onClose` окно не закрывается вовсе — только для блокирующего состояния системы.
- Текст: вопрос с объектом в кавычках-ёлочках и последствие фактом — «Объект пропадёт с карты. Его история останется доступна в отчётах.»

**Не делайте:** два окна друг над другом; «Вы уверены?», «ОК», «Да».
