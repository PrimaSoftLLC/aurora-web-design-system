Поле формы одним компонентом: ввод, число, выбор или многострочный текст со статичной подписью 12px над полем 40px.

**Потребитель задаёт** `label`, значение (`value`/`defaultValue` и `onChange`), при необходимости `as`, `options`, `hint`, `error`, `required`, `icon`, `suffix`, `mono`, `disabled`, `width`.

- Подпись статичная: плавающей подписи Material нет, поэтому ряд полей выравнивается при любой длине подписи. `labelMode="notch"` — только рядом с неперенесёнными формами `mat-form-field`.
- Единицы измерения — `suffix` (`км/ч`, `л/100км`), никогда не часть `label`.
- `mono` — для координат, IMEI, скоростей.
- Одна ошибка на поле: `error` заменяет `hint` и перекрашивает рамку. Несколько сообщений сразу не читаются.
- Рамка, ховер и кольцо фокуса — правила `[data-ds-field]` в `bundle.css`; компонент фокус не отслеживает.

**Не делайте:** свой `:focus`; стопку сообщений об ошибке.
