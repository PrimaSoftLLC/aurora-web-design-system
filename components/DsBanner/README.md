Баннер — единственная разрешённая постоянная поверхность сообщения: условие, которое остаётся верным, пока его не устранят.

**Потребитель задаёт** `tone`, `title`, текст в `children`, при необходимости `actions` (обычно одна `DsButton tone="secondary" size="sm"`), `onClose`, `compact`.

- `danger` объявляется как `alert`, остальные тоны — как `status`.
- Без `onClose` баннер нельзя скрыть — для сообщений, которые оператор не должен убирать.
- Полные предложения в теле — с точкой, заголовок — без.

**Не делайте:** баннер для результата действия — это тост; левую цветную полосу старой библиотеки.
