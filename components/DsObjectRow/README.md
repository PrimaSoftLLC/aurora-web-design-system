Строка объекта в дереве мониторинга: аватар в кольце свежести, состояние, связь, сервисное предупреждение и непрочитанное.

**Потребитель задаёт** `name` и `details` (одна готовая строка: скорость · водитель · последнее сообщение), при необходимости `state` с `course`, `signal`, `service`, `avatarSrc`, `freshness` с `freshnessLabel`, `unread` с `unreadPlacement`, выбор (`select`, `onSelectChange`), `active`, `onClick`, `indent`.

- Цвет диска — свежесть последнего сообщения: `live`, `recent`, `late`, `none`. Передавайте реальный возраст в `freshnessLabel`.
- Состояние и свежесть — разные факты: стоянка может быть свежей.
- `unread` 0 скрывает бейдж, больше 99 — «99+».
- Без `select` строка не выбирается; `indent` — отступ уровня, его передаёт дерево.
