# Сортировка в таблице

## Подключение к данным

`DsTable` сообщает выбранный ключ и направление через `onSort`.
Упорядочивание строк выполняет приложение. Для серверной пагинации
передавайте сортировку в запрос всего набора, а не сортируйте только
загруженную страницу.

```jsx
<DsTable
  columns={[{ key: 'name', label: 'Название', sortable: true }]}
  rows={rows}
  sortKey={sort.key}
  sortDir={sort.dir}
  onSort={(key, dir) => setSort({ key, dir })}
/>
```

При смене порядка сбрасывайте страницу на первую, сохраняя фильтры
и размер страницы. Демо выше использует локальные строки и показывает
форму запроса, не обращаясь к серверу.

Проверьте сортировку с клавиатуры и `aria-sort` активного заголовка.
Подробнее о свойствах — в [DsTable](../DsTable/README.md).
