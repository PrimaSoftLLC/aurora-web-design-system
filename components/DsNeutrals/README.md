# Нейтральные цвета

## Выбирайте роль цвета

Палитра выше показывает исходную шкалу. В интерфейсе используйте
семантические токены: они получают нужные значения в светлом и тёмном режиме.

| Задача | Токен |
| --- | --- |
| Фон страницы | `--ds-bg` |
| Поверхность панели | `--ds-surface` |
| Основной текст | `--ds-fg` |
| Второстепенный текст | `--ds-fg-muted` |
| Граница поверхности | `--ds-border` |

```css
.region {
  color: var(--ds-fg);
  background: var(--ds-surface);
  border: 1px solid var(--ds-border);
}
```

Не переносите HEX из образца в компонент. Отключённые состояния и значимые
границы контролов имеют собственные роли; обычная граница панели их не заменяет.
