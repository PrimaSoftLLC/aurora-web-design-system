# Подбор цветов темы

## Как пользоваться

Введите основной цвет бренда и цвет акцента. Калькулятор показывает
предлагаемые значения для light и dark, результаты проверки контраста
и пример их применения. Значения в полях меняют только этот пример.

## Как перенести результат

Сгенерированный CSS служит для просмотра палитры. Утверждённые значения
внесите в `tokens/source.json`, затем запустите `npm run build`.
Не заменяйте этим фрагментом сгенерированные стили пакета.

Проверьте текст на заливках, значимые иконки, ссылки, выбранные состояния
и оба цветовых режима на реальных компонентах. Прохождение отдельных
проверок калькулятора не заменяет проверку всего экрана.

Подключение атрибутами описано в разделе [«Цветовые темы»](../DsBrandThemes/README.md).
