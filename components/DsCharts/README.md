# Цвета и оформление графиков

## Подключение к ECharts

Адаптер читает токены из DOM-контейнера графика. Он доступен через
публичный вход пакета:

```js
import { dsEChartsTheme } from '@primasoftllc/design-system/echarts-theme';

const theme = dsEChartsTheme(chartElement);
```

При изменении темы или режима прочитайте значения заново и обновите
настройки графика. В Angular для этого есть `auroraWatchScopes`.

## Проверка данных

Сохраняйте соответствие цвета одной и той же серии при обновлении данных.
Проверяйте график с пропусками, одной точкой и пустым набором, а также
длинные подписи легенды и единицы измерения.

Примеры компонентов: [график датчика](../DsChart/README.md)
и [легенда](../DsChartLegend/README.md).
