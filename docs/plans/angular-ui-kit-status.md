# Статус Angular UI kit и нового сайта

**Обновлено:** 3 ноября 2026 года.

Здесь хранится текущее состояние, а не журнал каждого шага. При завершении задачи
обновляйте соответствующий пункт вместо добавления нового хронологического отчёта.
Согласованные решения — в [видении](angular-ui-kit-vision.md), команды и устройство
сайта — в [README сайта](../../documentation-site/README.md), правила библиотеки —
в [документации Angular UI kit](../../ng-ui-kit/docs/development.md).

## Готово

- Создан Angular-сайт с раздельной навигацией дизайн-системы и компонентов,
  настройками демонстраций, поиском по названиям и группам меню, оглавлением и якорями.
- Перенесены 22 страницы основ, включая справочник токенов, и три инструкции:
  подключение Angular, добавление компонентов и решения по миграции брейкпоинтов.
  Перенос текстов завершён; часть демонстраций ещё заменена заглушками.
- Перенесены шесть самостоятельных документов без левого меню: правила Angular UI kit,
  дизайн-правила, имена токенов, смена типографики, релизы и линтер.
  Список адресов находится в README сайта.
- Реализованы Icon, Button, FAB, Checkbox, Spinner и Form field с собственными страницами.
  API и правила применения описаны в README соответствующих компонентов.
- В Button и FAB используется общий Spinner; уменьшение движения сохраняет вращение.
- Готовые компоненты применены в подходящих самостоятельных примерах статей.
  Составные сценарии с недостающими компонентами сохранены как заглушки.
- Восстановлены самостоятельные примеры компоновки (breakpoints), выбора и фокуса
  (colors), вариантов сообщений (content) и кнопки настроек с пояснением (iconography).
  Сниппеты соответствуют работающим демонстрациям; отдельные компоненты библиотеки не добавлены.
- Унифицированы таблицы параметров, токенов и выравнивание матрицы Checkbox.
- Добавлены стандартные *.spec.ts с Karma/Jasmine: две команды unit-тестов
  библиотеки и сайта. Браузерные проверки сохранены в прежних файлах;
  дополнительная система запуска, кеширования и разбиения по файлам удалена.
  Инструкции — в [руководстве проверок](../../ng-ui-kit/tests/README.md).
- Старые команды и сайт сохранены. Публикация нового сайта и удаление React ещё не выполнены.

Сниппеты хранятся строками в типизированных объектах рядом со страницами.
strictTemplates проверяет ключи объектов, но не код внутри строк. Изменённые
примеры точечно извлекались и компилировались Angular-компилятором; постоянной
автоматической проверки всех сниппетов пока нет. Её добавление обсуждается отдельно.

## Отложенные решения и ограничения

- Карта: «Стрелки направления», «Маркеры и значки карты», «Трек на карте»;
  эталонные экраны Admin, AppShell, Monitoring — до согласования с заказчиком.
- Историческая памятка /migration/breakpoints относится к locator-front;
  её окончательное место на общем сайте ещё предстоит определить.
- /documents/component-pages и /documents/migration удалены из нового сайта:
  стандарт старого React-каталога и карта старых компонентов сюда не возвращаются.
  Их исходники сохранены для старого сайта. Служебные документы не переносятся автоматически.
- Переключение GitHub Pages, SPA fallback для прямых адресов и окончательные имена команд
  не согласованы как завершённая поставка. Локальный сервер с fallback не доказывает работу Pages.
- Сравнение четырёх режимов, расширенный поиск по содержимому/API и автоматическое
  получение таблиц Angular API остаются открытыми вопросами, а не готовыми возможностями.
- Единый источник текстов инструкций после удаления старого сайта нужно согласовать.
  Временное дублирование между сайтами допустимо.
- Интеграция с реальным приложением компании ещё не подтверждена.
  SSR, hydration и zoneless пока не заявлены.
- Настройки шапки, поиск и часть контролов примеров пока нативные. Их замена
  обсуждается по мере появления компонентов; отдельный Tooltip также ещё не создан.
- Вопросы WebStorm и настройки IDE отложены; .idea не изменяется.

## Form field: согласованный контракт

Одна связка и одна страница /components/form-field: оболочка отвечает за label,
рамку и размещение содержимого, dsInput сохраняет нативные input/textarea и штатные
Angular Forms value accessors. Ошибки и момент показа dsError задаёт приложение;
ошибка заменяет весь hint. Пустые строки label и сообщений резервируются по умолчанию.
maxRows ограничивает ручную высоту textarea, 0 оставляет её без ограничения.
В примере ngModel ошибка required появляется после blur и исчезает при исправлении.
В обычных формах Button и «Доступность» такую проверку также задаёт родитель;
novalidate отключает браузерное сообщение, reset в Button сбрасывает ошибку.
Подробный API и ограничения — в [README компонента](../../ng-ui-kit/src/components/form-field/README.md).

## Последний подтверждённый объём проверок

3 ноября выполнен полный набор verify с продолжением после найденных ошибок.
Все этапы подтверждены. Это не один успешный запуск npm run verify: первоначальные сбои и повторы
перечислены ниже. Коммит, публикация и обновление зависимостей не выполнялись.

- Unit-тесты библиотеки: 28/28, включая 10 тестов Form field. Unit-тесты сайта:
  4/4. Coverage в этом запуске не пересчитывалось.
- Сборки старого пакета и каталога, линтер (77 проверок), публичные экспорты,
  документация, release guards, чистая и воспроизводимая сборка прошли.
  React 19/Next-потребитель настоящего tarball также прошёл.
- Проверка упаковки, публичных входов и относительных путей CSS к шрифтам прошла.
  Проверки совместимости: 12/12 в Chromium, Firefox и WebKit.
- Основной браузерный набор: 198/207 при первом запуске. Восемь упавших сценариев
  старого каталога прошли отдельным повтором одним worker без изменения исходников,
  тестов или лимитов: ECharts, EmptyState, FAB, Field, полный офлайн-каталог,
  восстановление dev-сервера, hover и IconButton. В офлайн-каталоге проверены
  245 HTML-страниц, 76 превью, сравнение и семь шрифтов.
- Все растровые проверки и проверки каскада токенов прошли. Исходники, эталоны
  и общий снимок каталога остались неизменными.
- Новый сайт: форматирование, production-сборка с base-href=/site-check/,
  unit-тесты и все браузерные группы прошли. Статьи проверены с продолжением
  после сортировки; также прошли tokens, shell, guides, documents, components,
  checkbox и spinner. Группа components включает Icon, Button, FAB и Form field.
- В тестах нового сайта исправлены устаревшее ожидание React API сортировки,
  сравнение заголовков со служебной иконкой якоря и поиск обязательного поля
  Button по HTML-label вместо доступного имени textbox. Поведение компонентов
  ради прохождения тестов не менялось.
- Подготовка нового сайта больше не создаёт корневые fonts и assets/fonts,
  запрещённые repository-first контрактом. Собранные CSS и шрифты располагаются
  в .tmp/documentation-site-resources с сохранением опубликованных относительных
  путей. После исправления повторно прошли package, линтер, сборка и браузерные
  проверки нового сайта. Публичные пути пакета не менялись.
- Form field/dsInput отдельно прошли офлайн-установку tarball, production AOT
  и браузерные сценарии в Angular 19.2.25 и 20.3.34: ввод, number/null, Forms,
  ngModel, touched, ошибки, disabled/readonly, reset, проекция, ARIA, maxRows
