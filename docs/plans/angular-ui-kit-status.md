# Статус Angular UI kit и нового сайта

**Обновлено:** 2 ноября 2026 года.

Здесь хранится текущее состояние, а не журнал каждого шага. При завершении задачи
обновляйте соответствующий пункт вместо добавления нового хронологического отчёта.
Согласованные решения — в [видении](angular-ui-kit-vision.md), команды и устройство
сайта — в [README сайта](../../documentation-site/README.md), правила библиотеки —
в [документации Angular UI kit](../../ng-ui-kit/docs/development.md).

## Готово

- Создан Angular-сайт с раздельной навигацией дизайн-системы и компонентов,
  настройками демонстраций, поиском по названиям и группам меню, оглавлением и якорями.
- Перенесены 22 страницы основ, включая справочник токенов, и три инструкции:
  подключение Angular, добавление компонентов и решения по миграции брейкпоинтов.
  Перенос текстов завершён; часть демонстраций ещё заменена заглушками.
- Перенесены шесть самостоятельных документов без левого меню: правила Angular UI kit,
  дизайн-правила, имена токенов, смена типографики, релизы и линтер.
  Список адресов находится в README сайта.
- Реализованы Icon, Button, FAB, Checkbox и Spinner с собственными страницами.
  API и правила применения описаны в README соответствующих компонентов.
- В Button и FAB используется общий Spinner; уменьшение движения сохраняет вращение.
- Готовые компоненты применены в подходящих самостоятельных примерах статей.
  Составные сценарии с недостающими компонентами сохранены как заглушки.
- Унифицированы таблицы параметров, токенов и выравнивание матрицы Checkbox.
- Добавлены стандартные *.spec.ts с Karma/Jasmine: две команды unit-тестов
  библиотеки и сайта. Браузерные проверки сохранены в прежних файлах;
  дополнительная система запуска, кеширования и разбиения по файлам удалена.
  Инструкции — в [руководстве проверок](../../ng-ui-kit/tests/README.md).
- Старые команды и сайт сохранены. Публикация нового сайта и удаление React ещё не выполнены.

## Следующие шаги

1. Обсудить обязанности и API Input/FormField, затем согласовать объём реализации.
2. После следующего компонента подготовить ветку основы к PR и выполнить полный verify.
3. Далее разрабатывать компоненты отдельными ветками; их состав обсуждать по одному.

Сниппеты пока остаются строками в типизированных объектах. strictTemplates проверяет
имена ключей, но не компилирует код внутри строк. Возможная отдельная проверка
компилируемости сниппетов требует обсуждения.

## Отложенные решения и ограничения

- Карта: «Стрелки направления», «Маркеры и значки карты», «Трек на карте»;
  эталонные экраны Admin, AppShell, Monitoring — до согласования с заказчиком.
- Историческая памятка /migration/breakpoints относится к locator-front;
  её окончательное место на общем сайте ещё предстоит определить.
- /documents/component-pages и /documents/migration удалены из нового сайта:
  стандарт старого React-каталога и карта старых компонентов сюда не возвращаются.
  Их исходники сохранены для старого сайта. Служебные документы не переносятся автоматически.
- Переключение GitHub Pages, SPA fallback для прямых адресов и окончательные имена команд
  не согласованы как завершённая поставка. Локальный сервер с fallback не доказывает работу Pages.
- Сравнение четырёх режимов, расширенный поиск по содержимому/API и автоматическое
  получение таблиц Angular API остаются открытыми вопросами, а не готовыми возможностями.
- Единый источник текстов инструкций после удаления старого сайта нужно согласовать.
  Временное дублирование между сайтами допустимо.
- Интеграция с реальным приложением компании ещё не подтверждена.
  SSR, hydration и zoneless пока не заявлены.
- Настройки шапки, поиск и часть контролов примеров пока нативные. Их замена
  обсуждается по мере появления компонентов; отдельный Tooltip также ещё не создан.
- Вопросы WebStorm и настройки IDE отложены; .idea не изменяется.
