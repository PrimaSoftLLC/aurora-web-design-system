# Repository-first Design System Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Перевести дизайн-систему на самостоятельную разработку в Git, сохранить потребителей и упростить каталог и Angular-подключение.

**Architecture:** Три последовательных плана с работающим результатом на границе каждого. Данные токенов и исходники компонентов порождают пакет, каталог и проверяемый API; совместимые входы остаются адаптерами к одной реализации.

**Tech Stack:** Node 22 через mise, ESM, PostCSS, React 18.3, esbuild, Playwright, TypeScript 5.6, Angular compiler 19.0, существующий Stylelint.

**Spec:** [Согласованная спецификация](../specs/2026-10-02-repository-first-design.md), утверждена пользователем после коммита `6ff50ef`.

## Global Constraints

- «Репозиторий становится единственным источником дизайн-системы Aurora».
- «Существующие React-компоненты, HTML-примеры и содержательная документация сохраняются».
- «Минимальная поддерживаемая версия Angular остаётся 19».
- «Существующий контракт возврата провайдеров сохраняется».
- «Публичная схема `tokens.json` остаётся совместимой».
- «Публикация пакета, перенос приложений-потребителей и редизайн интерфейса не входят в реализацию».
- Node проекта — 22; команды запускаются `mise exec -- ...`; комментарии и документация — русский, коммиты — английский.
- DEFAULT/RED2, light/dark и cozy/compact остаются независимыми; старые props, exports, CSS-переменные и описанные пути подключения сохраняются.
- Зависимости добавляются только при реализации соответствующей задачи, с `--save-exact` и lock-файлом. Планирование ничего не устанавливает.
- Изоляция рабочей ветки — по `superpowers:using-git-worktrees` в начале исполнения; существующие пользовательские изменения не переносятся автоматически.
- Релизы и смена версии не являются частью этих планов; каждый этап добавляет запись в текущий CHANGELOG.

## Review Focus

1. Вложенный светлый DEFAULT внутри тёмного RED2 и обратная вложенность: проверка пересчёта алиасов — план 1, задача 3.
2. Путь с пробелом или кириллицей на Windows, неверный bash и код завершения дочернего процесса: план 1, задачи 1 и 5.
3. Старый Angular-алиас и новые импорты в одном приложении не создают разные DI-токены: план 2, задачи 1 и 3.
4. Нет ECharts, localStorage недоступен, сохранённая настройка невалидна: план 2, задачи 2 и 3.
5. Пример с собственными скоупами, отсутствующая декларация или вычисляемый default: план 3, задачи 1 и 2.

## Уточнения по результатам исследования

Плотность уже хранится в `tokens.json` как `value.light` / `value.ds-density-compact`.
Второй набор ручных значений плотности не нужен. Обнаружено другое дублирование:
типографика записана одновременно в `type.groups` и строках `type.families`.

Поэтому предлагается одно уточнение физического расположения исходника к §3
спецификации: редактируемая модель переносится в `tokens/source.json`; прежний
корневой `tokens.json` генерируется с прежней схемой и содержимым, включая
совместимые строковые представления типографики. Потребители не меняются.
Это уточнение является частью ревью плана, а не уже выполненным переносом.

Пакет содержит side-effect-скрипт `echartsTheme.js`; нельзя механически выставить
глобальное `sideEffects: false`. Новые Angular-файлы могут быть без side effects,
но имеющаяся регистрация глобальной функции должна пережить оптимизацию.

Прежние UI-тесты читают глобальные React/ReactDOM и бандл из файлов. Их меняем на
один тестовый загрузчик свежей сборки; JSX-превью получают совместимый namespace.
Не создаём второй React runtime внутри одного iframe или jsdom.

## Границы коммитов и проверок

- Каждый task завершается отдельным английским коммитом; содержание ограничено перечисленными файлами задачи.
- Перед коммитом: соответствующие тесты задачи, `git diff --check`, просмотр staged diff.
- На границе этапа: полный `npm run verify`, проверка tarball и чистого checkout.
- Эталоны исходной миграции закреплены за `8bf5c4d`; новый код не перезаписывает их.
- Скриншоты двух версий получаются одним установленным браузером на одной машине; обновление snapshots не заменяет расследование расхождений.
- Независимые команды чтения можно объединять; генерация, изменение файлов и зависимые проверки выполняются последовательно.

## Исполнение после ревью

Рекомендуется последовательное исполнение основным агентом: задачи тесно связаны
общими генераторами и форматами, поэтому постоянный контекст уменьшает передачу
незавершённых интерфейсов. В конце — независимое ревью всей ветки.
Альтернатива — отдельный исполнитель и ревьюер на каждую задачу; это дороже по
контексту, но даёт промежуточную независимую проверку.

## Результат исполнения — 2026-10-02

Все 14 задач трёх этапов выполнены последовательно в ветке `feat/repository-first`.
На границе каждого этапа проведено независимое ревью, замечания исправлены
с воспроизведением ошибки тестом. Последний коммит реализации — `caf0e0d`.

Итоговый `mise exec -- npm run verify` завершился с кодом 0: все проверки
сборки и контрактов, три независимых Angular AOT-потребителя, 18/18 браузерных
сценариев и офлайн-установка tarball. Проверены 201 HTML-страница, 69 превью,
четыре режима сравнения и семь локальных шрифтов. Значения токенов совпали
с закреплённой исходной версией; 68 карточек сравнивались точно по пикселям.
Обзорная карточка получила предусмотренное планом актуальное число примеров.

Новый чистый checkout `caf0e0d` отдельно прошёл `npm ci --offline`, `npm run build`,
проверку ссылок и `npm run check:pack`. Версия пакета остаётся `3.0.1`.

Границы результата: браузерная проверка выполнена в Chromium; 57 прежних
AXE-нарушений в шести примерах сохранены без новых нарушений. Остальные примеры
проверены на ресурсы и ошибки выполнения, но не прошли полный AXE-аудит.
Фактическая активация хука Codex требует доверия хостом; прежний защитный хук
сохранён до этой проверки. Публикация, перенос приложений-потребителей
и интеграция ветки остаются отдельными действиями.
